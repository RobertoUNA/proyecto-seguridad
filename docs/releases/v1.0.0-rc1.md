## 4. Resumen de Cambios, Excepciones y Limitaciones Conocidas (`Ítem 5.3`)

### 4.1 Novedades de la Versión
1. **Cruce Geoespacial (`FLOW-01`):** Endpoint `/api/cantones/:id/panorama` que calcula la relación entre delincuencia, accidentalidad e infraestructura de atención.
2. **Consultas Acotadas (`FLOW-02`):** Filtros dinámicos con cotas máximas para evitar denegación de servicio (`CTL-02`).
3. **Módulo de Logs Seguros (`CTL-06`):** Trazabilidad con `X-Correlation-Id` y hash SHA-256 (`actor_id`).
4. **Frontend desplegable fuera de compose (`6.2`):** el upstream de `/api` en nginx es configurable con `API_UPSTREAM` (por defecto `http://backend:3000`), con verificación TLS cuando es `https://`.
5. **Pruebas del Backend (`2.2`/`4.3`):** pruebas unitarias (Jest) y de integración API + BD (Supertest) incluidas en el check `3.1`.

### 4.2 Excepciones de Seguridad Vigentes
Todas las excepciones temporales se encuentran registradas formalmente en [`docs/ssdcl/REGISTRO-HALLAZGOS.md`](../ssdcl/REGISTRO-HALLAZGOS.md) con fecha de vencimiento `2026-12-15`:
- **`EXC-01`**: Paquetes transitivos de `@nestjs/platform-express` v10 (mitigado por API de solo lectura `GET`).
- **`EXC-02`**: Paquetes de tiempo de construcción en `devDependencies` de NestJS CLI.
- **`EXC-03`** (`HAL-04`): 9 CVE de severidad HIGH en **dependencias npm** del runtime del backend: `multer 2.0.2`, `body-parser 1.20.4` y `lodash 4.17.21`.
  - Aprobada formalmente por Billy Ugalde y aplicada en [`.trivyignore.yaml`](../../.trivyignore.yaml), por CVE y versión exacta (`purl`), con `expired_at: 2026-12-15`.
  - Las vulnerabilidades están **aceptadas temporalmente, no corregidas**.

### 4.3 Limitaciones Técnicas Conocidas
- **API Exclusiva de Solo Lectura:** La versión no procesa cargas multipart ni operaciones `POST`/`PUT`/`DELETE` públicas.
- **Granularidad Territorial:** Los datos se encuentran agregados a nivel cantonal, no distrital ni barrial.

```bash

```
